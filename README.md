# Hingot organization profile 

**Real conversations, spotlighted.**

Hingot is a social media platform built for real conversation. At its core is Hin — a fast, mobile-first microblogging feed where people post, poll, share images and links, and join the discussions that matter to them.

## What we're building
- 📰 **Hin** — microblogging feed: posts, polls, image posts, rich link previews
- 📍 **Local Events** — real-time local event and community reporting
- ⭐ **Global Spotlight** — give any post a wider audience
- 💬 **Messaging, voice & video calls** — built right in

## Stack
React + TypeScript · Cloudflare Workers · D1 · R2 · Durable Objects
